# Tourist Website

A simple, responsive tourism website template built with HTML, CSS, and static assets. It includes pages for home, locations, packages, booking, contact, and informational content.

## 🚀 Features

- ✅ Fully static HTML/CSS site (no backend required)
- ✅ Responsive layout for desktop and mobile
- ✅ Multiple pages:
  - `index.html` (home)
  - `locations.html`
  - `package.html`
  - `booking.html`
  - `contact.html`
  - `info.html`
- ✅ Organized assets folder structure
  - `assets/css/` for styles
  - `assets/files/` for images/docs (if present)
